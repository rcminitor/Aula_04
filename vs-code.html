Abrir o projeto no VS Code

Editar a configuração, rodar o terminal e conversar com o Claude sem sair do editor.

Dá para fazer a aula inteira só no PowerShell. Mas no VS Code você vê a pasta, edita o JSON com o editor avisando dos erros e mantém o terminal na tela — é como se trabalha de verdade.

1. Abra a pasta, não o arquivo

Essa é a parte que mais confunde: o Claude Code trabalha em cima da pasta aberta. Se você abrir só o index.html com dois cliques, ele não enxerga a configuração de .claude.

Duas formas de abrir a pasta certa:

  • No VS Code: menu File → Open Folder… (Ctrl+K depois Ctrl+O), escolha a pasta Teste_Aula_04 e confirme.
  • Ou, já dentro da pasta no PowerShell, um comando só:
PowerShell
PS C:\Users\...\Teste_Aula_04> code .

O ponto significa “a pasta atual”. Na primeira vez o VS Code pergunta se você confia nos autores da pasta — é a sua própria pasta, então marque a caixa e clique em Yes, I trust the authors.

A barra de título mostra o nome da pasta aberta. Se não disser Teste_Aula_04, você abriu a pasta errada.

A pasta .claude começa com ponto, mas aparece normalmente no Explorer do VS Code. Clique nela, abra o settings.local.json, cole a sua chave entre as aspas e salve com Ctrl+S.

O editor corrige você. Se faltar uma vírgula ou uma aspa, o VS Code sublinha a linha em vermelho e explica o erro ao passar o mouse. Salvar com o sublinhado aceso significa configuração quebrada — conserte antes de seguir.

3. O terminal fica dentro do editor

Abra com Ctrl+' (a tecla do apóstrofo) ou pelo menu Terminal → New Terminal. Ele já abre dentro da pasta do projeto, então é só rodar:

Terminal do VS Code
PS> powershell -ExecutionPolicy Bypass -File .\verificar-ambiente.ps1
PS> claude

Se o terminal abrir como cmd em vez de PowerShell, clique na setinha ˅ ao lado do + no canto do painel e escolha PowerShell.

4. A extensão do Claude Code

Existe uma extensão oficial que coloca o Claude num painel do editor, em vez do terminal. É opcional — a aula funciona sem ela.

  1. Abra o painel de extensões: Ctrl+Shift+X.
  2. Procure por Claude Code, da Anthropic.
  3. Clique em Install e recarregue o editor se ele pedir.

Ela usa a mesma configuração da pasta, então a sua chave e o seu modelo continuam valendo sem mexer em nada. Nas máquinas do laboratório, se a instalação de extensões estiver bloqueada, use o terminal — o resultado é o mesmo.
