01
Ambiente

Instalar o Node.js

Abra o PowerShell: tecla Windows, digite powershell, Enter. Depois rode:

PowerShell
PS> winget install OpenJS.NodeJS.LTS

Se o winget não existir na máquina, baixe o instalador LTS em nodejs.org e siga o assistente.

Feche e abra o PowerShell de novo. Sem isso o Windows não enxerga o comando recém-instalado — é o erro mais comum desta aula.

Sem permissão para instalar

Baixe o pacote Windows Binary (.zip), extraia em uma pasta sua e, a cada sessão do terminal, aponte o caminho:

PowerShell
PS> $env:Path = "C:\node;" + $env:Path
02
Ambiente

Conferir Node e npm

PowerShell
PS> node --version
v24.19.0
PS> npm --version
11.17.0

Qualquer Node a partir da versão 18 serve. Se aparecer “não é reconhecido como um cmdlet”, o Node não está instalado ou você não reabriu o terminal.

03
Ambiente

Instalar o Claude Code

PowerShell
PS> npm install -g @anthropic-ai/claude-code

Confira com claude --version. Se o comando não for encontrado, reabra o PowerShell; persistindo, rode npm config get prefix e confirme que esse caminho está na variável PATH.

Vai aparecer um monte de npm warn allow-scripts. Não é erro e não quebrou nada — a linha added N packages mostra que instalou. A seção “Ler a saída do terminal” explica o que é esse aviso e como calá-lo.

04
Acesso

Pegar a sua chave

A chave é a senha que identifica você no OpenRouter. Sem ela o Claude Code abre, mas nenhuma resposta chega. Ela é gerada no site, de graça, e leva dois minutos.

  1. Crie a conta. Vá a openrouter.ai e clique em Sign in, no canto superior direito. Dá para entrar com Google, GitHub ou e-mail — use o mesmo e-mail que você usa no curso, para não esquecer depois.
  2. Abra o painel de chaves. Já logado, clique na sua foto no canto superior direito e escolha Keys no menu. O endereço direto é openrouter.ai/settings/keys — a tela começa vazia.
  3. Clique em Create Key. Abre uma janelinha com dois campos. No Name, escreva um apelido só para você reconhecer a chave depois — pode ser ia-aula-04, meu-notebook, o que quiser; esse nome não vai para lugar nenhum além da sua lista. O campo de limite de crédito pode ficar vazio.
  4. Copie na hora. A chave aparece uma única vez, com um botão de copiar ao lado. Ela começa com sk-or-v1- e tem umas 70 letras e números. Se fechar a janela sem copiar, não tem como ver de novo — apague essa chave e crie outra.
  5. Guarde em algum lugar seu até o Passo 6: um bloco de notas do seu pendrive, o seu e-mail, o gerenciador de senhas. No Passo 6 ela vai para dentro do arquivo de configuração do projeto.

A chave é pessoal e vale como senha. Não publique no GitHub, não mande no grupo da turma e não deixe salva em máquina compartilhada do laboratório. Se vazar, volte em Keys, clique na lixeira ao lado dela e crie outra — a antiga para de funcionar na hora.

05
Acesso

Escolher o modelo

Não é preciso escolher. Use openrouter/free: o próprio OpenRouter encaminha cada pedido para um modelo gratuito que esteja no ar. Assim a configuração não quebra quando um modelo sai da lista.

Quer fixar um modelo específico? Veja a página de modelos gratuitos.

06
Configuração

Configurar o projeto

Na pasta da aula, abra .claude\settings.local.json e cole a chave do Passo 4 nos dois campos marcados.

Dá para editar no Bloco de Notas, mas o recomendado é o editor: abra a pasta no VS Code — ele mostra os arquivos, avisa se o JSON ficar inválido e traz o terminal na mesma tela.

.claude\settings.local.json
{
  "env": {
    "OPENROUTER_API_KEY": "sk-or-v1-COLE_SUA_CHAVE_AQUI",
    "ANTHROPIC_AUTH_TOKEN": "sk-or-v1-COLE_SUA_CHAVE_AQUI",
    "ANTHROPIC_BASE_URL": "https://openrouter.ai/api",
    "ANTHROPIC_MODEL": "openrouter/free",
    "ANTHROPIC_API_KEY": "",
    "ENABLE_TOOL_SEARCH": "false"
  }
}

Três detalhes derrubam a configuração:

  1. A base termina em /api, sem /v1. O Claude Code acrescenta o /v1/messages sozinho.
  2. ANTHROPIC_API_KEY fica vazio. Com qualquer valor, o Claude tenta falar com a Anthropic em vez do OpenRouter.
  3. O arquivo é JSON: cada vírgula e aspas contam. Salve em UTF-8.

ENABLE_TOOL_SEARCH em "false" faz o Claude Code enviar as ferramentas direto ao modelo, em vez de usar um recurso de busca que os modelos gratuitos nem sempre suportam.

Por que a configuração mora dentro da pasta. Este arquivo vale apenas neste projeto e tem precedência sobre o que estiver configurado no seu usuário. Cada pasta fica com a sua chave e o seu modelo, sem variável de ambiente global espalhada pela máquina — e, como o .gitignore ignora este arquivo, a chave não escapa junto com o código.

Ler a saída do terminal

aviso, erro ou nada

O terminal fala muito, e quase nada do que ele diz é problema. Três palavras separam o que importa:

added N packages

Terminou e deu certo. É a linha que vale.

npm warn

Aviso. A instalação seguiu em frente assim mesmo.

npm error

Aí sim parou. A causa está na primeira linha depois do erro.

só o prompt de volta

PS C:\Users\...> sozinho: o comando acabou e não tinha nada a dizer.

O aviso que todo mundo vai ver

Ao instalar o Claude Code, o npm imprime um bloco parecido com este:

PowerShell
added 2 packages in 5s
npm warn allow-scripts 1 package has install scripts not yet covered by allowScripts:
npm warn allow-scripts   @anthropic-ai/claude-code@2.1.278 (postinstall: node install.cjs)
npm warn allow-scripts Run `npm install -g --allow-scripts=@anthropic-ai/claude-code` ...

Traduzindo: alguns pacotes rodam um script logo depois de serem baixados — o postinstall. Como esse script executa código na sua máquina, as versões novas do npm passaram a listar quais deles você ainda não revisou. Por enquanto é só aviso: o script rodou e o pacote foi instalado — o added 2 packages na primeira linha é a prova. Em uma versão futura do npm esses scripts passam a ser bloqueados de verdade.

Para calar o aviso, aprovando o pacote de uma vez por todas:

PowerShell
PS> npm config set allow-scripts=@anthropic-ai/claude-code --location=user

Como saber se deu certo mesmo

Não discuta com o aviso: pergunte ao programa. Se claude --version devolve um número, está instalado, com aviso ou sem aviso. Essa é a regra geral desta aula — cada passo tem um comando que confirma o passo anterior, e o verificar-ambiente.ps1 faz todos de uma vez.

Exercício rápido: copie uma mensagem que você não entendeu, cole no Claude e peça: “explique esta mensagem do terminal e diga se preciso fazer alguma coisa”. Compare a resposta dele com o que esta página diz — aprender a checar a resposta de um modelo também é conteúdo da disciplina.
